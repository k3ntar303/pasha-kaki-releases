# パシャガキ

**同僚に送るのはこちらのページ → https://k3ntar303.github.io/pasha-kaki-releases/**

現場写真に、撮ってすぐ手書き・寸法・矢印などを書き込めるアプリです（Android 12 以上）。

## 最初のインストール

1. スマホのChromeで、下のリンクを押してダウンロードします。

   **[パシャガキをダウンロード](https://github.com/k3ntar303/pasha-kaki-releases/raw/main/pashagaki.apk)**

   「このファイルは有害な可能性があります」と出たら「ダウンロード」を押してください（Playストア以外のアプリには必ず出る表示です）。

2. ダウンロードが終わったら「開く」を押します。
3. 「この提供元のアプリを許可しない設定になっています」と出たら「設定」→「この提供元のアプリを許可」をONにして、戻ります。
4. 「インストール」を押します。
   - 「Google Play プロテクト」の確認が出たら「詳細」→「インストールする」を押してください。
5. アプリを開き、「写真へのアクセス」で「すべて許可」を選びます。

## 更新

新しい版ができると、アプリの写真一覧の上に「新しい版があります」と出ます。押すと更新できます。
（初めての時だけ「この提供元のアプリを許可」をONにする画面が出ます）

## 困った時

アプリの「設定」→「不具合を報告」で、動作の記録をLINEなどで送れます（写真は含まれません）。
